# Матрица покрытия ТЗ — отметки

Рабочая копия матрицы из [раздела 7 плана](../plan/README.md#7-матрица-покрытия-тз): по
каждому пункту — чем он подтверждён. Отсюда же слайд «Соответствие ТЗ».

Колонки — кто подтверждает: **Б** — бэкенд (автотест или `check_scenario.py`),
**ИИ** — Тимофей на тестовых фото, **Тел** — Павел на телефоне.
✅ — проверено, ⬜ — ждёт проверки, — — не касается.
Отмечает тот, кто проверил: ⬜ → ✅ и дата в скобках.

Бэкенд проверен 13.11: 99 автотестов (`cd backend && python -m pytest`) и
`check_scenario.py` — «ВСЁ РАБОТАЕТ» (ИИ — заглушка и поддельный сервис по контракту).
Настоящий ИИ-сервис ещё не подключён: всё, что в колонке Б связано с ИИ, перепроверяется
после адреса от Тимофея.
