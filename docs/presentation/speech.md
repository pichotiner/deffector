## Живой показ — Павел, 3 минуты

Передача данных на телефоне выключена. Перед звонком: `python stand.py --reset`.

1. Приложение открывается на камере. Наводим на QR насосного агрегата → «подтвердить».
   Одной фразой: «так же работает по табличке с номером, по фото и ручным выбором».
2. Карточка: модель Wilo CronoLine-IL, состав, параметры: вибрация и температура — из баз
   заказчика, в норме; давление на выходе красным — выше уставки.
3. «Требуют проверки» — список с причинами и подсказка «Наведите камеру на …».
4. Камера на агрегат: цветные рамки. Красный двигатель — признаки коррозии; красный
   манометр — давление выше уставки и просрочена поверка; жёлтая задвижка — 89 % ресурса
   по циклам; зелёная — «видимых проблем не обнаружено», с оговоркой.
5. «Анализировать» на узле → признаки, объяснение, уверенность.
6. Нажатие на рамку → карточка узла: норматив, расчётный ресурс, визуальный анализ,
   прошлые проверки, рекомендуемое действие.
7. «Дефект» с описанием → запись в истории, узел стал красным.

Павел: «Возвращаю слайды Андрею».
