# Видео: что снять и как смонтировать

## Готовый материал для защиты

**Используем одну [запись сценария](../demo/video/scenario.mp4), 2:48, 37,9 МБ.**
Она готова, подключена к слайду «Архитектура» и служит запасным показом.
[Содержание, таймкоды и происхождение](../demo/video/README.md).

Андрею: скачать файл заранее, открыть на весь экран и проверить воспроизведение
на своём ПК. Порядок в записи: адрес сервера → QR → карточка → двигатель → арматура → история.
Звук убран; видео сохранено целиком, без ускорения и вырезок.

Отключённые мобильные данные видны в прежней записи [scenario-offline.mp4](../demo/video/scenario-offline.mp4)
(2:36); в новой их не видно. Полный офлайн подтверждён участниками;
кабель и перезагрузка ПК не сняты и не обещаются. Специальный ролик-доказательство,
второй ракурс и пересъёмка ради прежнего протокола **не нужны** —
[актуальный план приёмки](../plan/acceptance.md).

## Если понадобится дополнительная запись

- Достаточно записи экрана телефона. Съёмка со стороны необязательна и полезна,
  только если нужно показать, на что направлена камера.
- Сохранять исходное разрешение, чтобы текст оставался читаемым; ориентация и
  длительность зависят от сценария. Звук можно убрать.
- Перед записью: `python stand.py --reset`, передача данных на телефоне выключена,
  уведомления выключены (режим «Не беспокоить»), заряд выше 50 %.
- Каждый шаг — с паузой 2–3 секунды на результате, чтобы на монтаже было что оставить.
- Указать осмысленное имя инженера в настройках. Исходные дубли сохранить.

## Необязательный монтаж с подписями

Скрипт [`docs/video/make_video.py`](video/make_video.py): по списку
вырезок сам собирает ролик — заставка, разделённый экран (запись экрана слева, съёмка со
стороны справа), подписи внизу, ускорение, MP4 H.264 1080p без звука. Нужен `ffmpeg`
(Windows: `winget install Gyan.FFmpeg`).

1. Записи положить в `docs/video/raw/` (в репозиторий эта папка не попадает).
2. [`scenario.json`](video/scenario.json) содержит версию с подписями для текущего
   исходника `raw/pavel-offline.mp4`, [`proof.json`](video/proof.json) — необязательную
   подборку фрагментов. Последняя не выдаётся за непрерывное доказательство офлайна.
   Оба плана используют только действия, имеющиеся в исходнике. Для другой записи
   нужно проверить таймкоды и подписи. `side_shift` задаёт смещение второй камеры.
3. `python docs/video/make_video.py docs/video/scenario.json` — получится
   `demo/video/scenario-captioned.mp4`; с `proof.json` — `docs/presentation/proof.mp4`.
   Эти варианты не заменяют автоматически опубликованный `scenario.mp4` и не
   требуются для сдачи. Их файлы не создавались в текущей подготовке.

Вручную — любой редактор с разделённым экраном и текстом: Clipchamp (есть в Windows 11),
DaVinci Resolve, Shotcut.

1. Синхронизировать две дорожки по хлопку или по моменту наведения на QR.
2. Любое ускорение явно подписывать; для текущего запасного файла оно не используется.
3. Подписи не должны закрывать важные действия и результаты.
4. Экспорт: MP4, H.264; проверить читаемость и открытие файла на ПК Андрея.
