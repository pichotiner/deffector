# Что выполнить на ПК перед сдачей

Время — МСК. Актуальный остаток — [короткий план](../plan/acceptance.md).
Команды ниже — PowerShell из корня репозитория, после попадания подготовки сдачи в `main`.
Если Git сообщает о локальных изменениях или расходящихся ветках, остановиться
на этом сообщении и передать его команде; принудительный сброс не нужен.

## Тимофей: обновить материалы и подготовиться к звонку

```powershell
git status --short
git switch main
git pull --ff-only origin main
git rev-parse HEAD
Start-Process .\docs\presentation\slides.pdf
Start-Process .\demo\video\scenario.mp4
```

1. Прочитать [речь](presentation/speech.md), [QA](qa.md) и
   [памятку по ИИ](../ai/notes/defense-14-11-cheatsheet.md).
2. Решить доступ жюри к закрытому репозиторию: публичный доступ либо приглашения
   конкретным аккаунтам жюри. Проверить доступ тем способом, которым будет сдача.
   Технические права администратора есть, но способ публикации требует твоего решения.
3. Получить ответ организаторов по обязательному минимуму 12 правил Энже.
4. Согласовать с командой точное время звонка после 18:00.

**Повторять GPU-прогон только ради этих документов не требуется:** рабочий код,
веса и пороги не менялись. Если Павел пришлёт ошибку, проверить её на своём ПК.
Для запуска с архивной Ollama, как в прежней настройке Тимофея:

```powershell
$env:PATH = (Resolve-Path ../ollama).Path + ";" + $env:PATH
$env:OLLAMA_MODELS = (Resolve-Path ../ollama/models).Path
python stand.py --check --image demo/reference/PU-001/case_pump_01.jpg
```

Это необязательный диагностический запуск. `--check` записывает осмотры и в конце
сбрасывает локальную БД к демо-данным. Модели заново скачивать не нужно.

## Павел: стенд, пять оставшихся строк матрицы и звонок

В согласованную паузу остановить уже запущенный стенд его `Ctrl+C`, затем:

```powershell
git status --short
git switch main
git pull --ff-only origin main
git rev-parse HEAD
Get-Content ai/.venv/installed.json
python stand.py --reset
```

В окне должно быть «СТЕНД ГОТОВ», «ИИ: настоящий». В приложении сверить адрес ПК
с этим окном, имя инженера сделать осмысленным. В ответ команде — HEAD и содержимое
`installed.json`; это закрывает уже существующую просьбу о версии стенда.

На телефоне выполнить только ещё не подтверждённое, без обязательной пересъёмки:

- [ ] «Компонент проверен» → новая запись в истории.
- [ ] «Обслуживание» и «Замена» → история, обновлённые даты и ресурс узла.
- [ ] В карточке узла открыть «Предыдущие результаты проверок» с рекомендациями.
- [ ] Чистый кадр (лист 9) → «видимых проблем не обнаружено» с оговоркой;
      отдельно увидеть «рекомендуется проверка», например на непригодном для анализа
      снимке. Не отмечать заранее, что модель обязательно выдаст ожидаемую категорию.
- [ ] Форма при потере локальной связи: ввести комментарий, отключить связь с ПК,
      попробовать сохранить; восстановить связь, нажать «Повторить», проверить историю
      и что осталось в форме. До повторной отправки убедиться, не сохранился ли осмотр.

Численный остаток ресурса уже подтверждён видео: 7,3 года и 220 циклов. Повтор
офлайна, переустановка APK и съёмка кабеля не нужны. Снимки Э1/Э3 и положительная
фотоидентификация нужны только если этот способ включаем в показ.

После 18:00, при активном звонке и трансляции, во втором окне PowerShell:

```powershell
python backend/check_scenario.py --image demo/reference/PU-001/case_pump_01.jpg --no-reset
```

Команда пишет тестовые осмотры. Прислать итог, время `detect` и анализа, указать,
что звонок/трансляция были включены. Перед живым показом после завершения проверки:

```powershell
python backend/reset_db.py
```

Один проход QR → карточка → двигатель/арматура → анализ → ресурс → запись.
Текст должен читаться у Андрея и Тимофея, анализ не должен зависать. Жёсткого FPS-порога нет.

## Андрей: открыть готовое и проверить передачу показа

После обновления `main` скачать/открыть [PDF](presentation/slides.pdf) и
[видео](../demo/video/scenario.mp4); проверить начало, анализ и конец записи,
полноэкранное воспроизведение. Прочитать обновлённую [речь](presentation/speech.md).
В HTML-презентации слайд 4 открывает тот же готовый MP4; папки `docs/` и `demo/`
нужно сохранить относительно друг друга. Для запаса открыть MP4 отдельным проигрывателем.

На звонке: принять трансляцию Павла, проверить читаемость и один раз перейти к
запасной записи. Новый монтаж не требуется. До 23:55 передать доступные жюри
исходники, APK, презентацию и ссылку на видео по правилам сдачи.
