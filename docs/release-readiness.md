## Исправления в итоговом варианте

Схемы API, словарь типов, веса и пороги сохранены.

1. **Поздняя ошибка детектора не ломает выбранный анализ.** Новый интерфейс и
   `DetectionTracker` из `main` сохранены. `selectedFrame` уже привязывает рамку
   к снимку; обработчик ошибки теперь применяет такие же проверки экрана, выбора,
   занятости и оборудования, как успешный ответ.
2. **Замена не возвращает старый дефект.** Результат анализа, начатого до замены,
   не восстанавливает состояние старого компонента; новый анализ в ту же секунду
   не теряется. ISO-время может содержать дробные секунды.
3. **Сброс БД атомарен.** Сбой наполнения демо-данными откатывает транзакцию.
4. **Стенд не маскирует ошибки.** Нет неявной заглушки при отсутствии `ai/run.py`,
   настоящий запуск перекрывает случайный `AI_STUB=1`, неуспех `--check` останавливает
   службы. `backend/run.py` передаёт код завершения Uvicorn.
5. **OpenAPI совпадает с зафиксированным JSON на Python 3.12.** Подпись HTTP 422 задана
   явно как в согласованной схеме; контракт не редактировался.
6. **Плохой снимок объясняется честно.** Свободный ответ VLM не подменяет сообщение
   о невозможности оценки. Скрипт качества прекращает расчёт при HTTP-сбое/техническом
   отказе, число рамок не называется точностью координат.
7. **Сборка и материалы согласованы.** Android собирается из пути с кириллицей;
   исправлены кавычки PATH и кодировка JVM тестов. APK пересобран с тестами/Lint.
    PDF печатается с отдельным профилем браузера; старый файл заменяется после
    завершения печати. Новые видео и трёхминутная презентация из `main` сохранены.
8. **Экспорт не ломается на длинном комментарии и XML-символах.** Подтверждены
   две ошибки новой реализации: HTTP 500 PDF на строке выше страницы и невалидный
   XML в Excel из-за управляющих символов. Строки PDF теперь делятся между страницами,
   недопустимые XML 1.0 символы удаляются только из выгрузки, история не меняется.
   Добавлены две регрессии и офлайн-тест входа/обоих отчётов; итог — 140 тестов бэкенда.
