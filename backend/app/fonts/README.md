# Шрифт для отчётов в PDF

`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` — DejaVu Sans 2.37, шрифт с кириллицей для
`app/reports.py`. Читается с диска, интернет не нужен.

Лицензия свободная (Bitstream Vera Fonts Copyright и дополнения DejaVu, шрифты Arev —
Tavmjong Bah): использование, копирование и распространение разрешены, в том числе в составе
программ. Полный текст — `LICENSE-DejaVu.txt` рядом.
