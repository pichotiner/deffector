# Оценка дополнительных визуальных правил Энже, 14.11

Ответ на обращение `TEAM_MESSAGES.md`, 13.11, 15:43. **Это оценка реализуемости по коду,
материалам и текущим проверкам, не реализация и не замер качества новых функций.**
Действуют четыре типа и четыре признака этапа 0. Контракт и рамки не меняются без
согласования троих и обязательного минимума с организаторами.

| Задача | Что возможно по RGB | Чего нет / что требуется |
|---|---|---|
| V1: уплотнение вала, капли | Описать различимые капли/подтёки на крупном плане; это уже один из признаков анализа | Детектор не локализует уплотнение отдельным классом. Нужны эталон зоны конкретного насоса, размеченные капли/блики/грязь, разные ракурсы и связь с нужным датчиком. Деградация и причина утечки по фото не подтверждаются |
| V2: рама и анкеры | Видимые коррозия и сломанный крепёж — кандидаты для предварительной проверки | Нет локализации каждого анкерного места и эталона комплектации. «Не найден болт» не значит «болта нет»; момент затяжки/ослабление и мягкая лапа не измеряются камерой. Нужны паспортная схема, видимые места, положительные/отрицательные примеры, закрытые зоны |
| V3: масло, MIN | Кандидат на чтение уровня при хорошо видимом стекле и известной шкале | Нет класса стекла, эталонов масла/MIN и калибровки цвета/освещения. По цвету RGB нельзя утверждать потерю смазывающих свойств. Нужны чистое/мутное стекло, блики, эталоны уровня и единицы/маркировка конкретного агрегата |
| V4: клеммник, перегрев | В текущем анализаторе есть следы перегрева электродвигателя, включая клеммную коробку; фото заказчика использованы | Отдельного детектора клемм/фаз нет. RGB видит потемнение/оплавление, не температуру и не ток. Сопротивление контакта/межвитковое замыкание не подтверждаются. Нужны схема фаз, локализация и соответствующие измерения; для тепловой карты — тепловизор |
| V5: стрелочный манометр | Возможна отдельная технология чтения шкалы и угла стрелки после локализации прибора | Сейчас детектор только даёт рамку, OCR приложения читает маркировку, не показание стрелки. Нужны центр/стрелка, начало и конец шкалы, пределы и единицы, перспективная коррекция, несколько шкал, закрытая/смазанная стрелка, эталонные показания. Манометр с телефона пока находится неустойчиво. SCADA и синхронных измерений нет; сравнение «>15 %» сейчас не реализовано |
| V6: кожух муфты | Можно исследовать наличие/повреждение, если ожидаемая зона полностью видна | Нет класса кожуха и эталона правильного положения. Пропуск детекции не доказывает отсутствие. Нужны паспортная геометрия, фото установленного/снятого/закрытого кожуха и крепежа. 3D-модель и привязка — задача согласования с Павлом |
| V7: поток/кавитация | Только внешние видимые проявления, если поток вообще виден | RGB не видит поток внутри непрозрачной трубы. Аудиоанализа и акустического датчика в прототипе нет. Нужны видео открытого потока или синхронная акустика/измерения; внутренний диагноз по одному снимку недоступен |

Для каждого расширения сначала нужны отдельные примеры: признак есть / нет / похожая
помеха / плохая видимость; варианты одного исходника держать в одной группе настройки
или контроля. Без этих данных нельзя обещать точность. Нынешняя проверка показала, что
даже явный неверный тип способен стать основанием для ложного анализа — отчёт
`quality-14-11-results.md`.

Сенсорные гипотезы должны храниться отдельно от `visual`, с источниками и временем.
Команды об остановке/обесточивании/протяжке не выводятся как установленный диагноз по
RGB. Текущий прототип не управляет оборудованием; работы выполняет уполномоченный
персонал по регламенту предприятия.
