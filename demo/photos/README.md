# Тестовые фото для ИИ-сервиса

Набор для проверки распознавания узлов и оценки дефектов (`ai/tools/evaluate.py`).
Разметка — [labels.json](labels.json). Папка `other/` — посторонние предметы: на них
не должно быть рамок, и они не должны определяться как оборудование.

Сейчас здесь только открытые фото с Wikimedia Commons. Набор нужно дополнить своими
снимками: нет кадров с течью и механическим повреждением и нет шкафа управления.
