# Эталонные фото для идентификации по изображению

По папке на образец оборудования, имя папки — идентификатор из базы:

```
demo/reference/PU-001/*.jpg   насосный агрегат
demo/reference/CC-001/*.jpg   шкаф управления
```

В каждую папку — 5–10 фото общего вида образца с разных ракурсов и при разном
освещении, снятых так, как его будет видеть телефон на показе. ИИ-сервис читает
эталоны при старте; после добавления фото его нужно перезапустить.

Сейчас для `PU-001` лежит одно открытое фото (источник — в `demo/photos/README.md`,
файл `pump_unit_01.jpg`), для `CC-001` эталонов нет — их нужно добавить после выбора
объектов показа.
