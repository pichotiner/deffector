## Происхождение и воспроизводимость

Источник — файл `2260017598579548595.mp4` с Google Диска команды: создан 14.11, 18:05 МСК,
168,41 с, 40 746 272 байт, звуковая дорожка AAC есть, но тихая (−91 дБ), то есть без звука.
SHA-256 исходника:
`acfb8bc891082fde706a6d38c75eb308f9ecf4b8370052e9a316ef9a055b8539`.

Видеодорожка скопирована **без перекодирования, вырезок и ускорения**, пустой звук удалён,
индекс MP4 перенесён в начало для быстрого открытия. Длительность видеодорожки — 168,37 с.
Из корня проекта, с FFmpeg в PATH:

```text
ffmpeg -i docs/video/raw/new-scenario.mp4 -map 0:v:0 -c:v copy -an -movflags +faststart demo/video/scenario.mp4
```

SHA-256 готового файла:
`4ca2224dafac8a389cadbc618eeb279136c0c9ed35465c60059cc336bd7c5fa2`.
SHA-256 сжатого видеопотока (`ffmpeg -map 0:v:0 -c copy -f streamhash -hash sha256`)
одинаков у исходника и результата:
`29968c92d235a2cd32361c3c00900971b8393cc997f5b07ab61fc54ea2d3f605`.

Весь файл декодирован FFmpeg без ошибок с нормализацией частоты на проверочном выходе
(`-vf fps=30 -f null -`); опубликованный MP4 сохраняет исходную переменную частоту.
