# Запасная запись сценария

[scenario.mp4](scenario.mp4) — готовый файл для защиты: **2:36, 34,4 МБ**, H.264,
590×1280, портретная запись экрана, без звука. Открывается локально; заранее скачать
на ПК Андрея и проверить полноэкранное воспроизведение. В HTML-презентации используется
этот же файл, отдельный `proof.mp4` для сдачи не нужен.

Это запись основного сценария, не всех вариантов интерфейса. В ней нет чистого листа 9,
регистрации обслуживания/замены, положительной фотоидентификации, отключения внешней
сети ПК или перезагрузки. Работа в полном офлайне отдельно подтверждена Павлом и
Тимофеем, приёмка закрыта 14.11, 13:00. Ошибочная рамка двигателя на арматуре и тестовое
имя инженера сохранены как в исходнике. На живом показе указать осмысленное имя инженера.

## Происхождение и воспроизводимость

Источник — запись Павла, переданная Тимофеем: контейнер 156,76 с, 37 056 448 байт.
SHA-256 исходника:
`37506749e091d792151ae753f6aafcfda40c636045cbda5c39429378a3a134dd`.

Видеодорожка скопирована **без перекодирования, вырезок и ускорения**, звук удалён,
индекс MP4 перенесён в начало для быстрого открытия. Длительность самой видеодорожки —
156,004 с; разница с исходным контейнером относится к дорожкам/таймингам контейнера.
Исходник для повторения положить в игнорируемую папку `docs/video/raw/pavel-offline.mp4`.
Из корня проекта, с FFmpeg в PATH:

```text
ffmpeg -i docs/video/raw/pavel-offline.mp4 -map 0:v:0 -c:v copy -an -movflags +faststart demo/video/scenario.mp4
```

SHA-256 готового файла:
`1a597501fe1a7d9bbac504b09c77009fc321afc7c863ae0c35b85a83a59237ea`.
SHA-256 сжатого видеопотока (`ffmpeg -map 0:v:0 -c copy -f streamhash -hash sha256`)
одинаков у исходника и результата:
`61f00a152bb4219ceab6ae65556db5581664438d6dc3a25e05efa13b2d49e194`.

Весь файл декодирован FFmpeg без ошибок с нормализацией частоты на проверочном выходе
